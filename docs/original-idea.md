# Original Website Idea

This document preserves the original idea so it does not have to be stored separately.

## Original Wording

> create personal brand website molodchyk.com "I love building things" photo of me working at desk, either the live calendar integration of what I do or github integration, and localise it

## Preserved Requirements

- Domain: `molodchyk.com`
- Type: personal brand website
- Core phrase: "I love building things"
- Main visual: photo of me working at a desk
- Dynamic signal:
  - live calendar integration of what I do, or
  - GitHub integration
- Localization: the site should be localized

## Interpretation

The site should communicate active building, not just list credentials. It should show what is being made, what is currently receiving attention, and how the projects connect.

## Privacy Note

Live calendar integration should be treated carefully. Public calendar data can leak private commitments, locations, availability, meeting names, and habits. A safer first implementation is GitHub activity plus a manually controlled "Now" section. Calendar integration can be added later only with explicit filtering and review.
